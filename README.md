# make-knowledge-cards

一个 Skill：把**用户粘贴的文章**或**本地 Markdown / TXT 文件**，提炼成 **5～8 张知识卡片**。

每张卡片包含四要素：**标题、核心知识、简明解释、例子或自测问题**。

## 特点

- **一卡一点**：一张卡片只讲一个知识点，不混合主题。
- **忠于原文**：只提炼原文已有的信息，不引入外部知识、不推测、不编造。
- **自动去重**：重复、同义的内容合并，不会出现两张讲同一件事的卡片。
- **不凑数**：信息不足时输出更少的卡片，并说明原因，而不是硬凑到 5 张。
- **语言随原文**：中文材料生成中文卡片，英文材料生成英文卡片（正文、字段标签、来源行都跟随）。

## 目录结构

```
skills/make-knowledge-cards/
├── SKILL.md              # 技能定义：工作流程、卡片规范、质量红线、自检清单
└── agents/openai.yaml    # 技能界面元数据（名称、简介、默认提示词）
tests/                    # 测试用文章及生成结果（用于验证技能效果）
```

## 安装

把 `skills/make-knowledge-cards/` 整个目录复制到你的技能目录即可：

- 用户级（对所有项目生效）：`~/.workbuddy/skills/`
- 项目级（仅当前项目）：`<workspace>/.workbuddy/skills/`

## 使用方法

- **方式一（粘贴正文）**：把文章正文直接粘贴到对话里，说"帮我做成知识卡片"。
- **方式二（本地文件）**：给出 `.md` / `.txt` 文件路径，例如"把 `notes/遗忘曲线.md` 做成知识卡片"。

## 输入输出示例

**输入**（`tests/04-sparse-zh.md`，节选）：

> 番茄工作法由弗朗切斯科·西里洛在 1980 年代末提出。它的核心做法是：专注工作 25 分钟，然后休息 5 分钟，这样一个"工作—休息"的循环称为一个番茄钟；每完成四个番茄钟，进行一次较长的休息。
>
> 它的价值在于把注意力切分成短的、可管理的时间段，降低开始工作的心理阻力，并通过固定休息减少疲劳。

**输出**（`tests/04-sparse-zh.cards.md`，节选）：

```markdown
> 来源：04-sparse-zh.md｜共 2 张卡片

> 注：原文只提供了 2 个足以独立成卡的知识点，因此未强行凑到 5 张。

## 卡片 1：番茄工作法的做法

- **核心知识**：番茄工作法由弗朗切斯科·西里洛在 1980 年代末提出，做法是专注工作 25 分钟、休息 5 分钟；每完成四个番茄钟，进行一次较长休息。
- **简明解释**：一个"工作—休息"循环称为一个番茄钟，四个番茄钟后进入一次较长休息。
- **自测**：一个番茄钟由哪两段组成，各多长？完成几个番茄钟后休息加长？

---

## 卡片 2：番茄工作法为什么有用

- **核心知识**：它把注意力切分成短的、可管理的时间段，从而降低开始工作的心理阻力，并借助固定休息减少疲劳。
- **简明解释**：原文把它的价值归结为两点——更易开始，以及更不易疲劳。
- **例子**：面对一项拖延已久的大任务时，改成"先做 25 分钟"，比想着"做完整个任务"更容易启动。
```

## 支持范围

| 支持 | 暂不支持 |
| --- | --- |
| 用户粘贴的正文 | 网页抓取（需联网获取的 URL 正文） |
| 本地 `.md` / `.txt` 文件 | PDF、docx 等其他格式 |
| — | 导出 Anki（apkg） |
| — | 任何图形界面 |
